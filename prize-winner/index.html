1. Set up the prize structure

Upload a file or enter prizes manually
What should the prize structure contain?
  • One row per award or prize, such as Champion, Runner-up, Best U12, or Best Girl.
  • Winner is the award title/category; the tool fills the actual player name in the result.
  • Add a Type of Winner column with an explicit value on every row: Main Prizes or Special Prizes. The tool will not guess the prize type from its name.
  • Special-prize eligibility is configured using Club/City, Typ and/or Gr from the final ranking file.
  • Prize can contain cash, an item, medal, trophy or a combination. Numeric amounts help compare prize values.

3. Prize allocation rules

Confirm these before generating winners
Counts all players matching that award's eligibility rule, before prize-conflict rules.
Special prizes are processed in prize-list order (No / row order). Overall prizes are allocated first, then each special prize goes to the highest-ranked eligible player who has not already received a prize, unless multiple prizes are allowed.
How to configure special prizes
  • Use Overall rank for Champion, 1st Runner-up, 2nd Runner-up and other general placing prizes.
  • Use Special category for awards such as Best U12, Best Girl, Best Veteran or Best School.
  • For every Special Prize, select exactly one eligibility parameter — Type, Group, or Club/City — and enter the value that qualifies. For example, Best U12 can use Group = U12 if that is how the ranking file labels players.
  • If fewer players than the minimum match an award rule, that prize is marked not awarded. The tool will not silently give it to an ineligible player.
  • Both winner allocation and the final exported list follow the prize structure order (No column, or row order when No is not provided). Main Prizes are allocated first; Special Prizes are allocated afterward using the configured eligibility parameter.
