3. Map source headers

Tips for accurate mapping
  • Match the actual data, not just a similar column name. For example, Player Name → Name and FIDE ID → FIDE-No.
  • Check sample values and map the player's full name.
  • Ignore unrelated columns such as phone number, email or online usernames.
  • Keep ID and rating columns as text where necessary so leading zeros are preserved.

4. Automatic field rules

Choose the source of truth
Important tips before generating fields
  • ID no uses YYMMDD plus a 3-digit sequence (e.g. 261015001), resetting for each registration date. Choose the real registration-date column; missing/invalid dates block export.
  • IC-derived birth dates and sex must be reviewed. Century inference can be ambiguous.
  • Sex mapping: BOY / MALE / LELAKI → blank; GIRL / FEMALE / PEREMPUAN → F. Malaysian IC last digit: even → F, odd → blank.
  • For age categories, select blank Type so Swiss Manager can calculate using event settings, or map the existing Type column.
  • Do not invent official FIDE IDs, ratings or titles.
